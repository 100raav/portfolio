# Saurav Bichha — Portfolio

Animated, futuristic, single-page portfolio for a full-stack software engineer.

## Stack
- React 18 + TypeScript + Vite
- Pure CSS animations (particles, typewriter, scroll-reveal, glowing gradients)
- Live data from the GitHub API (repositories, followers, profile stats)

## Sections
Hero · Profile Summary · Education · Experience · Selected Work · Live Repositories · Tech Stack · Contact

## Local
```bash
npm install
npm run dev      # dev server
npm run build    # type-check + production build
npm run preview  # preview the built app
```

## Deploy
`.github/workflows/deploy.yml` builds and publishes `dist/` to GitHub Pages on every push to `main`.

All projects, roles and stats on the site are real and verifiable in [the public GitHub profile](https://github.com/100raav).
